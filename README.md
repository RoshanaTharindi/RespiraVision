# RespiraVision

An educational respiratory image analysis prototype
built using C++17, Python and machine learning.

## Project Objectives

- Implement fundamental image-processing algorithms in C++.
- Extract numerical features from grayscale images.
- Integrate C++ processing with Python.
- Experiment with basic machine learning techniques.
- Build a simple interactive visualisation dashboard.

## Technology Stack

- C++17
- CMake
- OpenCV
- Python
- NumPy
- Scikit-learn
- GoogleTest
- Docker
- Streamlit
